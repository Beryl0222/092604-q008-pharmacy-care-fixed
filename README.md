# 药师连续照护协议

本项目提供药师连续照护协议的服务端基础，覆盖协议全生命周期：患者同意范围、药师执业与门店授权、药物清单版本、服务目标、回访事件、异常升级、服务额度与跨店交接。系统只记录处方与执行事实，不做诊断、不改写医嘱。

## 目录

- `src/pharmacy_care/domain.py` 领域对象与状态常量（角色、协议/回访/异常/额度状态）。
- `src/pharmacy_care/store.py` SQLite 表结构与事务写入（含额度流水、幂等回执、复核单、审计日志）。
- `src/pharmacy_care/service.py` 业务规则：签署资格、冻结、额度事务、交接、视图与恢复。
- `src/pharmacy_care/api.py` 进程内 JSON 请求边界。
- `tests/` 覆盖各业务规则。

## 业务规则

- **同意与冻结**：回访类型必须在患者同意范围内；收到新处方或患者撤回同意时，依赖旧信息的未来回访被冻结并退回预占额度，历史记录（流水、审计）依法保留。被冻结的回访可重排到当前清单版本。
- **签署资格**：一次回访只能由签署时点具备执业资格、且获得当前门店授权的药师签署；销售人员不能关闭安全异常（非安全异常由药师或合规关闭）。
- **幂等与复核**：离线补录与支付回调按业务键去重；同键不同内容不生效，生成复核单，仅合规人员可处理。
- **额度事务**：预约预占、签署完成、取消/冻结退回额度均在同一事务中；协议转店后原门店的待执行回访取消并退回额度，原门店不能继续消费。
- **角色视图**：患者看计划与同意状态；药师看执行依据（当前清单版本、回访依据版本、未关闭异常）；合规看未解决风险、费用去向与审计历史。
- **重启恢复**：服务启动即扫描过期回访标记为逾期，并恢复未关闭异常与待复核队列。

## 运行

运行测试：`python3 -m pytest -q`（或 `PYTHONPATH=src python3 -m unittest discover -s tests`）

检查源码：`python3 -m compileall src`

本地冒烟：`printf '%s' '{"action":"health"}' | PYTHONPATH=src python3 -m pharmacy_care.cli`

项目只使用 Python 标准库，运行期间不连接其他服务。
